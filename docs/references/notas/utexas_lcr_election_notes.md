## Tese central

Apresenta eleição em anel **assíncrono** com IDs únicos: algoritmo O(n²) (LeLann) e melhoria O(n log n) (Chang–Roberts), com esboço de **correção** (só o maior ID completa o anel).

## O que tomamos no lab

- Vocabulário **líder / maior ID**.
- Referência para comparar complexidade de mensagens.

## Diferença no nosso caso

- Implementação não segue o pseudocódigo LCR linha a linha.
